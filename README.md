# GitPractics

Учебный репозиторий лабораторной работы № 1 по ООАиП.

Цель работы — освоить ветки Git, Pull Request, замечания ревьюера и исправления в той же рабочей ветке.

Основная ветка: `develop`.

Порядок работы описан в [git-workflow.txt](git-workflow.txt).

Каждая учебная задача выполняется в отдельной ветке. Изменения включаются в `develop` через Pull Request после проверки вторым участником.
