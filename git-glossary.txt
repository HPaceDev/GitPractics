Основные термины Git

Репозиторий — файлы проекта и история их изменений.
Коммит — сохранённое состояние проекта с сообщением и идентификатором SHA.
Ветка — изменяемая ссылка на коммит, позволяющая вести отдельную линию работы.
Индекс — подготовленные изменения, которые попадут в следующий коммит.
Push — отправка локальных коммитов в удалённый репозиторий.
Pull Request — предложение включить изменения рабочей ветки в целевую ветку.
Ревью — проверка изменений другим участником перед слиянием.
Конфликт — ситуация, в которой Git не может автоматически объединить изменения.
Merge — объединение историй веток; отдельный коммит слияния нужен не всегда.
Rebase — перенос коммитов на другую базу с изменением их идентификаторов.
Squash — объединение изменений нескольких коммитов в один коммит.
